# Fanzone Prototype

Mobil-first web uygulama prototipi.

## Kurulum

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

3. Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Özellikler

- ✅ Next.js 14 (App Router)
- ✅ TypeScript
- ✅ Tailwind CSS (Mobil-first)
- ✅ Responsive tasarım
- ✅ Modern UI/UX

## Notlar

- Uygulama mobil görünümü üzerine tasarlanmıştır
- Maksimum genişlik mobil cihazlar için optimize edilmiştir
- Tablet ve desktop görünümleri için responsive breakpoint'ler kullanılabilir
